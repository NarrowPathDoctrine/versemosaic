# VerseMosaic

Standalone public GitHub Pages website for the **VerseMosaic** Android Scripture study app, by Narrow Path Doctrine Ministries.

- [Homepage](https://narrowpathdoctrine.github.io/versemosaic/)
- [Privacy Policy](https://narrowpathdoctrine.github.io/versemosaic/privacy.html)

## GitHub Pages

Enable this site at repository **Settings → Pages → Build and deployment → Deploy from a branch**, select **main** and **/(root)**, and save.

Once the Pages deployment succeeds, the above URLs become public. Use the Privacy Policy URL in the Google Play Console privacy policy field and link it inside the app (for example, Settings or About).

## Maintenance

Keep the policy and the Google Play Data safety declaration in agreement with the shipped app. Review them when app permissions, backup behavior, external links, analytics/advertising services, or network use change. The page text describes the intended app behavior but must be verified against the final app build.
